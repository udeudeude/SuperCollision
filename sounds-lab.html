Native Sample Lab

EXPERIMENTAL · 07

Experimental isolated SuperCollider playback test. Uses the same native language and synthesis engine as SuperCollision, without changing the main Code page. This is not a browser sampler or a second sound engine. Uncompressed PCM WAVE files are read directly as sample values for SuperCollider, without resampling or editing; other formats still use compatible browser decoding for native transfer.

1 / Initialize SuperCollider

Requires cross-origin isolation and the existing compiled SuperCollider runtime. Starting may use substantial memory. An audio unlock button remains available after startup. Opening a saved preset automatically transfers its original once native audio is unlocked, but never starts playing without a separate Play tap.

2 / Load an existing recording

Audio is decoded for ingestion (the browser may resample to the engine output rate), transferred to SuperCollider with /b_alloc and /b_setn, then checked against the server's /b_getn sample readback. Transfers can be cancelled. Playback uses native SuperCollider PlayBuf. The library's original audio file is never replaced.

3 / Native sample region & audition

Non-destructive controls for the loaded sample. Playback, region selection, speed and looping are performed by SuperCollider's native PlayBuf, BufRd and Phasor instruments, never a browser audio engine. Loop seams use a short equal-power overlap calculated by SuperCollider. Changing controls takes effect the next time you tap Play.

Drag horizontally across the waveform to select a region, or use the accessible start and end sliders below. The waveform is a read-only visualization; audio processing stays in SuperCollider.

Region: 0% to 100% · 1× · Volume 16% · One shot

Native equal-power loop crossfades reduce boundary clicks; difficult sources can still produce audible artifacts. Stop releases only this laboratory player. Source audio is never overwritten.

4 / Save a reusable instrument

Save the selected region, speed, loop and volume as a Library preset referencing the original recording. No audio is duplicated or modified. Export an editable .scd script to use with desktop SuperCollider; export the original audio separately from Library, then choose it when the script asks for a file.

Only a verified native buffer can become a preset. A missing or deleted source recording will not be silently replaced.
