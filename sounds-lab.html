Native Sample Lab

BUILD 2026.11.20.14

Experimental isolated SuperCollider playback test. Uses the same native language and synthesis engine as SuperCollision, without changing the main Code page. This is not a browser sampler or a second sound engine. Uncompressed 8/16/24/32-bit PCM, 32/64-bit floating-point and standard extensible WAVE files are read directly as sample values for SuperCollider, without resampling or editing; other formats still use compatible browser decoding for native transfer.

1 / Initialize SuperCollider

Requires cross-origin isolation and the existing compiled SuperCollider runtime. Starting may use substantial memory. An audio unlock button remains available after startup. Opening a saved preset automatically transfers its original once native audio is unlocked, but never starts playing without a separate Play tap.

2 / Load an existing recording

Supported uncompressed WAVE values are read directly without browser decoding or resampling. Recordings with a different sample rate from your device retain their original timing and pitch through native SuperCollider playback-rate compensation. Other formats may be decoded and resampled by the browser solely for ingestion. Audio is transferred to SuperCollider with /b_alloc and /b_setn, then checked against the server's /b_getn sample readback. Transfers can be cancelled. The diagnostics report how many samples the native server has acknowledged and distinguish allocation, transfer and readback stalls. Playback uses native SuperCollider PlayBuf. The library's original audio file is never replaced.

Non-destructive controls for the loaded sample. Playback, region selection, speed and looping are performed by SuperCollider's native PlayBuf, BufRd and Phasor instruments, never a browser audio engine. 4 / Save a reusable instrument

Save the selected region, speed, loop and volume as a Library preset referencing the original recording. No audio is duplicated or modified. Export an editable .scd script to use with desktop SuperCollider; export the original audio separately from Library, then choose it when the script asks for a file.

Only a verified native buffer can become a preset. A missing or deleted source recording will not be silently replaced.
