Native Sample Lab

EXPERIMENTAL · 02

Experimental isolated SuperCollider playback test. Uses the same native language and synthesis engine as SuperCollision, without changing the main Code page. This is not a browser sampler or a second sound engine.

1 / Initialize SuperCollider

Requires cross-origin isolation and the existing compiled SuperCollider runtime. Starting may use substantial memory. An audio unlock button remains available after startup.

2 / Load an existing recording

Audio is decoded for ingestion (the browser may resample to the engine output rate), transferred to SuperCollider with /b_alloc and /b_setn, then checked against the server's /b_getn sample readback. Transfers can be cancelled. Playback uses native SuperCollider PlayBuf. The library's original audio file is never replaced.

3 / Audition

Audio is generated solely by SuperCollider. This initial test supports one short mono or stereo sample at a time, with no effects or editing. Stop ends only the laboratory's sample player.

Status / diagnostics

Start the native engine to begin.
